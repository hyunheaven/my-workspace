시작하기 · Getting Started

Local Private Mode

My Workspace는 페이지·템플릿·업무·일정을 나만의 작업 흐름으로 정리하는 로컬 전용 공간입니다. 아래에서 시작해보세요.

1. 템플릿 찾기

업무 / 학습 / 개인 범주를 고른 뒤 부서·직무별로 검색합니다.

2. 페이지 작성

템플릿을 선택해 페이지를 만들고 제목과 본문을 바로 수정합니다.

3. 내 문서 확인

저장된 문서를 다시 열어 수정합니다. 변경 충돌은 서버에서 확인합니다.

템플릿 라이브러리의 카드를 선택해 편집 가능한 개인 페이지를 만드세요. 페이지, 업무 및 일정은 로컬에 저장됩니다.
4. Page Tree

템플릿 문서를 상위·하위 페이지로 분류합니다.

5. Task Database

프로젝트 업무를 표와 상태 보드로 확인합니다.

6. Calendar

일정과 업무 마감일을 월·주·일 단위로 확인합니다.
