# Security Review
Threat model REST, WebSocket, Search, Attachments, Agent/RAG, backup, GitHub and local process. Check deny-by-default on read/write, no title existence leaks, token revocation, mutable permission cache and RLS bypass role. Check no external API/telemetry, signatures, license/SBOM, secret leakage, sandbox & synthetic fixtures. Request a human security signoff when company policy demands it; an AI review is not certification.
