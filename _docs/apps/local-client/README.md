## Overview

The local-client directory contains the static front-end assets that implement the local client workspace UI. At the top level there are no runtime source files; instead the functionality is provided inside the static/ subdirectory. The static assets implement a main UI entry point (index.html) plus supporting CSS and JavaScript that drive the page canvas, database UI, theming, and workspace transfer utilities. These files together form the client-side presentation and interaction layer for the local workspace.

The static/ subdirectory consolidates all HTML, CSS, and client-side JavaScript required by the local client. Within static/ the primary entry (index.html) is supported by app.css and app.js for general styling and behavior, with additional thematic styles (themes.css) and utilities for workspace transfer and database UI. This directory’s role in the larger system is to provide the self-contained front-end bundle that renders the local workspace UI and handles client-side interactions, theming, and workspace transfer operations used by the application.


### File Organization

All front-end resources are grouped under a single subdirectory (static/) to separate static client assets from server or other code; the root of local-client intentionally contains no files and serves as a container for the static asset bundle.
