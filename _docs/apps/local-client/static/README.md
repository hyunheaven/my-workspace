# 📁 static

> **Purpose:** Contains the static front-end assets (HTML, CSS, and client-side JavaScript) that implement the local client workspace UI, page canvas, database UI, theming, and workspace transfer utilities.

## Overview

This directory holds the static resources for the local client workspace. At the root it provides a main UI entry (index.html) and supporting CSS and JavaScript files: app.css and app.js implement the general visual styling and client-side behavior for the local client; themes.css (and a related but not-yet-documented themes.js) provide workspace chrome and canvas background theming; workspace-tools.css, custom-databases.css, and custom-databases.js implement styling and client logic for workspace UI components and a custom databases interface. Specialized UI and behavior for page canvases and linked-page views are implemented by pagecanvas.js and page-database-views.js respectively, while workspace-transfer.js handles importing/exporting workspace transfer data in Markdown and CSV formats and wires the transfer dialog UI.


### File Organization

Files are grouped by front-end feature area: a top-level application shell (index.html, app.js, app.css), database-related UI and logic (custom-databases.css, custom-databases.js, page-database-views.js), canvas/page utilities (pagecanvas.js, themes.css, themes.js), and workspace utility/transfer tools (workspace-tools.css, workspace-transfer.js). This keeps styling and behavior for each feature co-located for easier maintenance.

## Architecture Notes

- Static assets are organized by feature area so styling and scripts for a given UI area are co-located—this reduces cross-file coupling when maintaining a feature.
- Index.html serves as the single HTML entry; JavaScript modules implement feature behavior and are intended to be loaded by the page rather than run standalone.
