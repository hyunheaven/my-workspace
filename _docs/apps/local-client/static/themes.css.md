## Overview

This CSS file defines workspace chrome and canvas background theming for the local client UI. It establishes a set of CSS custom properties (variables) for a default light palette at the document root and then overrides subsets of those variables for named workspace themes (sage, indigo, clay, dark) via data-workspace-theme and data-page-theme attributes. The file maps those variables into concrete visual styles for common UI regions (layout, topbar, sidebar, forms, buttons, dialogs, and canvas surface variants) so that changing the workspace or page theme updates colors, borders, focus outlines, and background textures consistently across the interface.

In addition to palette variables and theme overrides, the stylesheet contains rules that target specific component patterns and states (hover, active, selected, focus-visible, placeholder) and implements a few background treatments (paper/mint/mist backgrounds and a grid pattern using radial-gradient). It also styles theme-related controls such as a compact workspace-theme-button with a conic-gradient swatch and a modal dialog for theme selection, including a backdrop style and box shadow.
