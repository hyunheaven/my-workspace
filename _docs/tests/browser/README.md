## Overview

This directory hosts a collection of browser-focused test modules and helper harnesses used to validate workspace behaviors across several versioned galleries. At the root level there are versioned workspace test modules (workspace_v013.py, workspace_v014.py, workspace_v110.py, workspace_v110_canvas.py, workspace_v120.py, workspace_v120_canvas.py, workspace_v130.py). These modules implement headless Chromium validation tests, end-to-end validation routines for per-page appearance and tag handling, regression tests for template persistence and link handling across restarts, canvas-specific editor interaction checks (IME composition, draft recovery, block commands, long documents), and Playwright-based harnesses for nested block editing and structured clipboard behavior.

Taken together the files provide a progression of acceptance and regression scenarios keyed to workspace versions. Canvas-specific helpers (files with _canvas in their names) concentrate on editor and complex interaction checks, while the versioned workspace files exercise broader end-to-end scenarios such as workspace persistence, view history restoration, colored tabs, and custom database workflows. The directory's role in the larger system is to provide automated browser validation coverage for features that require a Chromium-based environment (headless or Playwright-driven), ensuring UI behaviors and cross-restart persistence are validated against a local isolated server used by the test harnesses.


### File Organization

Files are organized by workspace version and test focus at the repository root of this directory. Each filename encodes the workspace version and whether it contains canvas/editor-specific helpers ("_canvas"). This flat, version-oriented layout makes it straightforward to find tests for a particular workspace release and to distinguish general end-to-end scenarios from canvas/editor interaction helpers.
