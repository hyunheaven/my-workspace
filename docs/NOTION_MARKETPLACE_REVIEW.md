# Notion Marketplace Reference & Rights Review — 2026-11-15

## 검토 사실 (공식 웹페이지의 표시값)
- Notion Marketplace는 업무·생활·학습 분야의 다수 템플릿을 제공함.
- 조회 시 무료 업무 템플릿 카테고리 약 **52,925**, 무료 생활 템플릿 카테고리 약 **21,752**로 표시됨. 카테고리가 중복될 수 있고 수량은 시점에 따라 변동하므로 합산해 총 개수로 주장하지 않음.
- 제작자 다수가 참여하고 각 템플릿의 저작권 및 배포 조건이 동일하지 않음.
- Notion Help는 템플릿을 Notion Workspace에 추가·복제하는 흐름을 설명하며, 제작자가 다른 Workspace로의 이동/복제를 제한할 수 있음을 밝힘.

## 권장 정책
1. 무료 제공 = 별도 제품 재배포 허락이 아님. 라이선스·제작자 동의 불명확하면 원본을 복사하지 않음.
2. 일반적인 업무 방식·정보 구조(회의·계획·테스트·RCA·학습 등)만 참고하고, 고유 표현·디자인·샘플 데이터·이미지·상표/로고를 그대로 가져오지 않음.
3. 프로젝트 정적 카탈로그는 자체 작성한 80개 템플릿임. Marketplace 템플릿 ID나 페이지 내용을 가져온 것이 아님.
4. 제3자 템플릿을 실제로 수록할 경우 아이템별 `creator`, `source_url`, `permission_scope`, `approval_id`, `license`, `reviewed_at`의 명시적 기록과 회사 승인 필수.
5. 기업 운영 모드에서는 외부 Marketplace 접속·자동 크롤링·자동 설치/동기화를 지원하지 않음.
6. 음성/영상/외부 폼·이미지·임의 첨부, 스크립트/AI Agent 포함 템플릿은 전면 제외 또는 구조만 자체 재설계.

## 미검증
- 개별 템플릿별 회사 내 별도 제품에 대한 재배포 라이선스: 확인되지 않음.
- Notion API로 Marketplace 전체를 적법하게 일괄 등록할 수 있는지 여부: 확인되지 않음 (구현하지 않음).
- 자체 작성 80개 템플릿의 회사 정책 및 UI 검토: 미완료.
