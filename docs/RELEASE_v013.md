# My AI Workspace v0.13

## 템플릿 라이브러리

기존 152종의 ID와 정의를 보존하고 업무 60종, 학습 24종, 개인 36종을 추가했습니다. 새 템플릿 120종은 10개 컬렉션으로 나뉩니다.

| 범주 | 신규 컬렉션 |
|---|---|
| 업무 | 프로젝트·제품, 팀 운영·회의, 문서·지식관리, 연구·데이터, 업무 성장·채용 |
| 학습 | 수업·시험, 독서·자기학습 |
| 개인 | 계획·습관, 가계·생활, 여행·취미 |

템플릿 카드의 미리보기에 실제 섹션·표·체크리스트가 표시됩니다. 카드나 미리보기 창의 페이지 만들기를 선택하면 별도의 페이지로 생성됩니다. 새 페이지의 콘텐츠는 SQLite에 보관됩니다. 추천과 인기 주제 분류는 앱의 편집 분류입니다.

공개 Notion 마켓플레이스의 무료 카테고리와 인기 컬렉션을 참고해 업무 흐름을 선정했습니다. 120종의 설명, 표, 예시 및 카드 디자인은 이 앱용으로 작성했습니다. Notion 마켓플레이스 원본을 직접 가져온 템플릿은 0종입니다. 개인 라이브러리 링크는 로그인 화면으로 연결됐으며 비공개 항목은 포함하지 않았습니다.

## 테마 및 페이지 도구

- **테마**에서 웜 뉴트럴, 세이지 그린, 인디고, 테라코타, 다크 중 하나를 선택합니다. 페이지 배경은 기본, 아이보리 종이, 민트, 블루 미스트, 도트 그리드 중에서 고릅니다.
- 테마, 템플릿과 페이지 즐겨찾기, 최근 페이지는 브라우저별로 저장합니다. 주소나 포트, 브라우저 프로필을 바꾸면 설정이 달라질 수 있습니다.
- **모든 문서**에서 제목과 함께 본문, 표 셀, 이전 템플릿 입력값을 검색할 수 있습니다. 최근 수정 순서로 최대 100건을 표시합니다.
- **페이지 복제**는 현재 페이지의 제목, 콘텐츠와 블록을 같은 계층에 복사합니다. 하위 페이지, 업무 및 캘린더 항목은 기존 페이지에 남습니다.
- **페이지 이력**에서 과거 내용을 열고 **이 버전 복원**을 선택하면 현재 계층을 유지하면서 새 리비전으로 복원합니다. 복원 직전 리비전도 계속 조회할 수 있습니다.

페이지 템플릿 표는 편집 가능한 텍스트 표입니다. 범용 데이터베이스의 사용자 정의 속성, 관계형 속성·롤업·수식, 팀 실시간 공동 편집은 후속 범위입니다. 음성 녹음, 동영상 편집, 외부 미디어 임베드와 외부 서비스 배포를 포함하지 않습니다.

## 검증

배포 ZIP의 검증 화면은 `docs/evidence-v013/`에 있습니다. Windows 실기 검증은 [RUN_LOCAL.md](../RUN_LOCAL.md)에 따라 별도 DB로 진행합니다.

| 검증 | 결과 |
|---|---|
| Python | 새 라이브러리 검사 5건, v0.12 통합 검사 8건, 기존 회귀 검사 26건 통과. 272종 전체의 미리보기·생성·저장 스키마·재조회를 포함합니다. |
| Chromium 156 · Linux | 컬렉션·검색·탭·즐겨찾기, 읽기 전용 미리보기, 더블 클릭 중복 방지, 자동 저장, 새 페이지 배경 및 테마 유지, 본문 검색, 복제와 이력 복원, 재시작 및 프로젝트·업무·캘린더 통과. 브라우저 요청은 테스트 루프백으로 제한됐고 페이지 오류는 0건입니다. |
| SQLite | v0.12 배포본으로 만든 합성 DB의 문서·표·체크리스트·이력과 기존 요청 키가 유지됐습니다. 무결성 검사 `ok`, 외래 키 위반 0건입니다. |

검증 환경에 pytest가 없어 기존 회귀 검사 26건은 fixture 어댑터로 실행했습니다. Windows 11 실기와 고정 의존성 조합은 검증 대상에 남아 있습니다.

Python 테스트는 `python -m pytest -q`를 사용합니다. 브라우저 검사는 승인된 Playwright 환경에서 다음 명령으로 실행할 수 있습니다.

```text
python tests/browser/workspace_v013.py --chromium "/path/to/chromium" --screenshots ./qa-screenshots
```
