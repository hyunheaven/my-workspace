# My AI Workspace v0.14

| 기능 | 사용 방법 |
|---|---|
| 색상 9종 | 오른쪽 위 **테마**에서 워크스페이스 색상을 선택합니다. 현재 페이지의 색상은 **현재 페이지**에서 별도로 지정하거나 워크스페이스 색상을 따르게 할 수 있습니다. |
| 페이지 배경 10종 | 기본, 아이보리 종이, 민트, 블루 미스트, 도트 그리드, 줄눈 노트, 모눈 종이, 여백 줄노트, 크림색 메모, 로즈 페이퍼 중에서 선택합니다. **새 페이지 기본 배경**과 현재 페이지 배경을 따로 지정합니다. |
| 열린 페이지 탭 | 문서를 열면 상단에 탭이 생깁니다. 최대 24개를 유지하며 탭을 클릭해 문서를 전환하고 ×로 닫습니다. 테마 설정에서 문서별로 탭 색상 8종 또는 기본값을 선택하면 페이지 트리에도 같은 색이 표시됩니다. |
| 사이드바 메뉴 색상 | **테마 → 사이드바 메뉴**에서 메뉴와 색상을 각각 선택합니다. |
| 페이지 태그 | 제목 아래에서 최대 16개를 추가·삭제합니다. 태그를 누르면 **모든 문서**에서 해당 태그와 정확히 일치하는 문서를 볼 수 있습니다. 문서 검색어와 태그 필터는 함께 사용할 수 있습니다. |

페이지 색상·배경·탭 색상과 태그는 문서와 함께 SQLite에 저장됩니다. v0.13 브라우저의 페이지 배경은 같은 브라우저에서 계속 표시되며, 배경을 다시 선택하면 SQLite에 저장됩니다. 워크스페이스 색상, 새 페이지 기본 배경 설정, 사이드바 메뉴 색상 및 열린 탭 목록은 브라우저에 저장됩니다.

페이지 복제에는 SQLite에 저장된 스타일과 태그도 포함됩니다. 본문 리비전 복원은 현재 테마와 태그를 유지합니다. 기존 문서·블록·이력은 그대로 읽을 수 있습니다.

## 검증

- Linux Chromium에서 페이지별 노트 배경과 색상, 페이지 탭 전환·닫기, 메뉴 색상, 태그 추가·삭제·필터, 재시작 후 새 브라우저 세션 유지 검사를 통과했습니다.
- 기존 v0.12와 v0.13 브라우저 회귀 검사도 통과했습니다.
- Python `unittest` 15건과 기존 fixture 어댑터 회귀 26건이 통과했습니다. v0.13 릴리스로 만든 합성 SQLite DB에서 문서·블록·이력을 읽고 새 속성을 저장했습니다. SQLite 무결성 검사와 외래 키 검사도 통과했습니다.
- Windows 11 실기 및 고정 의존성 조합은 미검증입니다.

브라우저 테스트와 화면 캡처는 아래 명령으로 재현합니다.

```text
python tests/browser/workspace_v014.py --chromium "/path/to/chromium" --screenshots ./qa-screenshots
```
