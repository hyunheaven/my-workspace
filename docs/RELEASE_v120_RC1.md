# My Workspace v1.2.0-rc.1

개인 PC에서 사용하는 로컬 작업 공간입니다. v1.1.0 후보에 중첩 편집, 사용자 정의 데이터베이스, 페이지에 연결된 보기와 로컬 파일 교환을 추가했습니다. Windows 11 실기 검증 전의 릴리스 후보입니다.

| 작업 | 지원 범위 |
| --- | --- |
| 블록 편집 | 최대 6단계 들여쓰기, 하위 블록 접기, 묶음 이동, 다중 선택·복사·붙여넣기·삭제, 실행 취소, 기존 페이지 이력에서 복원 |
| 데이터베이스 | 여러 데이터베이스 생성, 기본 속성과 관계·롤업·수식, 레코드 편집과 검색, 표·보드·캘린더·타임라인·갤러리 |
| 보기 설정 | 보기별 정렬·필터와 유형별 그룹 또는 날짜 속성, 페이지에 원본 보기를 연결하고 레코드를 열어 편집 |
| 관계와 계산 | 관계가 같은 PC의 데이터베이스 레코드를 참조합니다. 롤업은 개수·합계·평균·최솟값·최댓값, 수식은 두 숫자 속성의 사칙연산을 지원합니다. |
| 파일 교환 | UTF-8 Markdown 문서 가져오기·저장, 정의된 스키마에 CSV 레코드 추가 및 저장 |

## 저장과 호환성

이전 SQLite 경로와 `EAW_DATA_DIR`를 사용합니다. 기존 블록의 깊이는 0이며, 블록 깊이 컬럼과 사용자 정의 데이터베이스 관련 테이블을 추가합니다. 페이지에 연결된 보기는 원본 데이터베이스·보기 ID를 참조합니다. 기존 업무 데이터베이스와 프로젝트·캘린더 데이터를 새 스키마에 옮길 필요가 없습니다. 구버전으로 되돌릴 때는 업데이트 전 DB를 별도로 열어 사용합니다.

## 파일 교환 범위

- Markdown은 일반 텍스트, 제목, 목록, 체크리스트, 인용, 코드, 표, 내부 페이지 링크와 이 앱의 들여쓰기를 지원합니다. 문서는 표시용 블록으로 변환합니다. HTML·스크립트와 외부 미디어는 실행하거나 가져오지 않습니다. 테마·태그·연결된 보기·페이지 이력은 DB에 보관합니다.
- CSV에는 제목·메모와 직접 입력하는 속성을 포함합니다. 관계 링크·롤업·수식은 DB에 보관하며 CSV에는 포함하지 않습니다. UTF-8 CSV를 열 때 문자열이 수식으로 실행되지 않도록 수식 형태의 텍스트 앞에는 작은따옴표를 붙여 저장합니다. 가져오기는 1회 100행, 요청당 최대 256 KiB이며 행 검증에 실패하면 배치 전체를 취소합니다.
- 두 파일 형식은 선택한 데이터의 교환용입니다. 전체 데이터 및 설정 백업에는 SQLite 백업을 사용합니다. [Windows 실행 및 업데이트 가이드](../RUN_LOCAL.md)

## 비교 범위

Notion의 블록 편집, 사용자 정의 속성, 연결된 보기, 롤업과 여러 데이터베이스 보기의 흐름을 참고했습니다. 이 후보의 편집기는 텍스트 중심이고, 수식은 제한된 연산을 사용합니다. 페이지 이력은 지원하고, 보기 구성과 레코드의 독립 버전 이력은 후속 범위입니다. 협업·공유 서버와 AI는 별도 제품 범위입니다.

- [Notion 편집 도움말](https://www.notion.com/help/writing-and-editing-basics) · [데이터베이스 속성](https://www.notion.com/help/database-properties) · [관계와 롤업](https://www.notion.com/help/guides/using-relation-and-rollup-properties) · [데이터베이스 보기](https://www.notion.com/help/views-filters-and-sorts)

## 검증 결과

- Linux의 `python -m pytest -q`에서 테스트 56개와 서브테스트 716개가 통과했습니다.
- Chromium에서 기존 회귀 스크립트 5개와 새 브라우저 스크립트 2개가 통과했습니다. 새 스크립트는 `tests/browser/workspace_v120.py`, `tests/browser/workspace_v120_canvas.py`입니다. 실행 형식은 `python <스크립트> --chromium <Chromium 실행 파일>`입니다.
- 브라우저에서 Markdown 다운로드·재가져오기, 페이지 이력 복원, 다섯 데이터베이스 보기, 롤업·수식 재계산, 연결 해제 후 원본 보존, CSV 왕복, 서버 재시작 후 검색을 확인했습니다. 블록 접기·이동·클립보드·실행 취소와 재실행 후 저장도 검증했습니다.
- v1.1.0 후보에서 만든 합성 DB를 복사해 업그레이드했습니다. 기존 페이지·테마·고대비·태그·탭 색상·즐겨찾기가 유지됐고 원본 DB의 SHA-256, 복사본 무결성과 외래 키를 확인했습니다.

## 확인 환경

Windows 11 실기·Microsoft 한국어 IME·Edge의 파일 대화상자는 실기 검증 대상입니다. PowerShell 명령과 업그레이드 절차는 [실행 가이드](../RUN_LOCAL.md)를 참고하세요.
