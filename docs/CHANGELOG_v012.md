# My AI Workspace v0.12 변경 내역

기준 소스는 `My_AI_Workspace_v0.11_Windows11.zip`입니다.

| 영역 | v0.12 변경 |
|---|---|
| 템플릿 갤러리 | 152종 카드를 선택하면 새 페이지가 생성됩니다. 템플릿 이름, 설명, 필드와 안내문을 편집 가능한 제목 및 본문 블록으로 옮기고 작업 유형에 맞는 체크리스트와 표를 포함합니다. |
| 탐색 | 생성된 페이지를 페이지 트리에 표시하고 편집기를 엽니다. |
| 페이지 편집 | 인라인 제목과 본문, 체크리스트, 표 셀을 직접 수정합니다. 빈 문단의 `/` 메뉴, 키보드 선택과 저장 피드백을 개선했습니다. |
| 자동 저장 | 연속 편집을 모아서 저장합니다. 페이지 이동 전에 저장을 시도하고 실패하거나 충돌하면 상태를 표시합니다. |
| 페이지 이력 | 개설 및 이후 저장된 리비전의 제목과 블록을 조회합니다. |
| 기존 로컬 기능 | v0.11 문서와 템플릿 입력값을 유지하고 프로젝트, 업무 테이블·보드, 캘린더 및 대시보드를 기존 SQLite 데이터와 연결합니다. |

## 구현 결정

- 원본 템플릿은 앱에 포함된 카탈로그에서 읽습니다. 새 페이지에 복사한 블록은 페이지별 식별자로 관리하며 사용자가 페이지에서 독립적으로 수정할 수 있습니다.
- 생성 API가 문서, 부모 연결, 초기 블록, 첫 이력 및 요청 키를 SQLite의 한 트랜잭션에 저장합니다. 같은 요청 키로 재시도하면 처음 만든 페이지가 반환됩니다. 사용자가 새 요청으로 카드를 다시 선택하면 별도의 복사본이 생성됩니다.
- 표는 일반 텍스트 셀의 배열로 저장합니다. 템플릿 표와 셀은 페이지 작성에 사용합니다. 필터, 수식, 관계 및 업무 데이터베이스 연결은 후속 작업입니다.
- 기존 문서 및 블록 데이터를 유지하는 가산 마이그레이션을 사용합니다. 기존 페이지는 v0.11의 마지막 저장 상태부터 이력을 조회할 수 있습니다. 첫 수정 시 그 상태와 새 리비전을 한 트랜잭션에 기록합니다. 이력은 조회용입니다.
- 로컬 요청은 기존 루프백 바인딩, 요청 검증 및 브라우저 콘텐츠 정책을 따릅니다. 새 탭과 재실행 동작은 로컬 SQLite 데이터에서 확인할 수 있습니다.

실행 및 복사본 업그레이드 절차는 [Windows 실행 가이드](../RUN_LOCAL.md), 남은 과제는 [개발 계획](../PROJECT_PLAN.md)을 참고합니다.
